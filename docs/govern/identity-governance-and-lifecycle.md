## Objective

Automate identity and access lifecycle decisions so users get the right access at
the right time with auditable controls.

![Identity lifecycle diagram from Microsoft Learn](https://learn.microsoft.com/en-us/entra/id-governance/media/identity-governance-overview/identity-lifecycle.png)

*Source: [Identity governance overview](https://learn.microsoft.com/en-us/entra/id-governance/identity-governance-overview).* 

## Lifecycle domains

| Domain | Focus |
| --- | --- |
| Joiner lifecycle | New identity creation and baseline access assignment |
| Mover lifecycle | Access adjustment when role or department changes |
| Leaver lifecycle | Timely access revocation and identity deactivation |
| External lifecycle | Time-bound collaboration and automatic cleanup |

## Governance enablers

1. Lifecycle workflows for event-driven tasks.
2. Access packages for governed access requests.
3. Recurring access reviews and recertification.
4. Privileged role lifecycle protections.

## Operating outcomes

- Reduced manual onboarding and offboarding effort.
- Better entitlement visibility across business owners.
- Stronger compliance evidence for audits.
